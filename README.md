# Frogger em Pygame

Versão simplificada inspirada em Frogger, criada em Python e Pygame
como mostrado no vídeo. Atravesse a estrada desviando dos carros e
use os troncos para cruzar o rio até a margem de cima.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python frogger.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use as **setas** para mover o sapo. Ao bater, cair na água ou sair da
tela, ele volta ao início. Feche a janela para sair.

## Código passo a passo

O arquivo `frogger.py` contém o jogo completo. A pasta `passos/` mostra as
quatro versões executáveis apresentadas no vídeo: sapo, carros, rio e chegada.
